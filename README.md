# Cucumber Framework - Capstone Project

Cucumber-based automated tests covering login/logout, cart, checkout, and product search scenarios.

## Prerequisites

* Java 26
* Maven 3.9+ (or use the included Maven Wrapper)

## Run Tests

Using Maven Wrapper:

```bash
./mvnw clean test
```

## Reports

After execution, reports are available in:

```text
target/cucumber-report.html
target/cucumber-report.json
```
